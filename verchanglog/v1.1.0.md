# fc-history-query v1.1.0 版本更新日志

**发布日期**：2026-10-08
**版本类型**：功能更新

---

## 版本概述

v1.1.0 修复了部分私有云平台查询虚拟机列表返回 405 的问题，新增命令行版本查询与二进制在线更新能力，便于在服务器上直接完成版本查看与升级。

## 问题修复

- **修复部分平台查询虚拟机列表报 405**：`/vms` 等查询接口要求 `Accept` 头携带版本号，此前统一发送不带版本号的 `Accept`，导致部分平台的查询接口一律返回 `405 Method Not Allowed`（响应体为一张 HTML 错误页），页面表现为「获取虚拟机列表失败」。现登录与全部资源请求统一携带 `application/json;version=8.0;charset=UTF-8`，各平台查询接口均正常返回。

## 新增特性

- **命令行版本查询**：新增 `-v` / `--version` 参数，输出版本号后退出，例如 `fc-history-query v1.1.0`。
- **发布产物注入版本号**：Linux、macOS、Windows 各架构二进制与 Docker 镜像构建时写入实际版本，`-v` 输出真实版本而非占位值。
- **在线更新脚本**：新增 `scripts/update-fc-history-query.sh`，分页抓取 GitHub 全部 Release 并列出可选版本，选择后自动完成下载校验、停止服务、替换二进制、重启并做进程存活检查，启动异常时自动回滚旧版本。
- **服务启停脚本**：新增 `scripts/run.sh`，提供 `start` / `stop` / `restart` 三个操作，含 PID 管理与运行日志。

## 优化与修复

- Docker 镜像新增阿里云镜像仓库推送，并禁用 provenance 以兼容更多镜像仓库。
- Go 模块代理支持通过构建参数配置，便于网络受限环境构建。

## 升级说明

- 本版本无需数据迁移或配置调整。
- 已有部署可直接使用更新脚本升级，也可手动替换二进制后重启服务。
- 使用更新脚本时需保证 `INSTALL_DIR`（默认 `/data/fc-history-query`）下存在 `run.sh`。
- v1.0.2 及更早的二进制不支持 `-v`，更新脚本会自动改读更新时写入的 `.version` 文件来识别当前版本。

详细使用方式见项目根目录的 [README.md](../README.md)。
